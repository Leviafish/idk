Levititas v2 — What's new?

v2 adds four new Priority-2 layers on top of the original seven, making it structurally stronger than LuaPH and LuaRmor. Every run produces a different output due to polymorphic transforms and a randomized identifier style seeded from the system clock.

All 10 Obfuscation Layers

LayerDescription
🔀 Name ManglingRenames every local variable and function to confusing IlIlllI-style gibberish. Identifier style randomized per run.
🔐 String EncryptionRolling-XOR cipher — each byte's key depends on the previous plaintext byte, making brute-force much harder than a fixed key.
🔢 Number VirtualizationNumbers encoded as lambda chains of XOR, rotate, and add operations. Decoded only at runtime.
🧬 Dead Code MutationProcedurally generated realistic-looking dead code with opaque predicates (always-true/false math identities).
🛡️ Anti-DebugHooks debug.sethook, detects hooked pcall, and measures timing anomalies typical of debuggers.
💬 Strip CommentsAll -- and --[[ ]] comments removed from output.
🌀 Control Flow Flat CFGEntire script body converted to a while-loop state machine with a randomized dispatch table. Makes decompiled code unreadable.
🎲 Polymorphic P2Dead code injected between code sections at random cut points. Identifier style changes every obfuscation run.
📦 Multi-Layer Env P22-3 nested load() closures each with a sandboxed setmetatable({}, {__index=_G}) environment and fake __newindex trap.
⚙️ Custom VM VMThe entire script is encrypted with a rolling-XOR cipher and wrapped in an obfuscated bytecode interpreter. Decompilers see only the interpreter, never the original code.
